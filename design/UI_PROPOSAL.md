# Proposition d'Interface - Plateforme Éducative Burkina Faso

## Palette de Couleurs Officielle

| Couleur | Hex | Usage |
|---------|-----|-------|
| **Bleu doux** | `#2F80ED` | Couleur principale, boutons actions, liens |
| **Vert naturel** | `#27AE60` | Succès, validation, progression |
| **Jaune soleil** | `#F2C94C` | Étoiles, récompenses, alertes douces |
| **Fond blanc cassé** | `#FAFAFA` | Arrière-plan principal |
| **Ocre africain** | `#F2994A` | Accents, badges, touches culturelles |
| **Beige** | `#FFF8ED` | Cartes, zones de contenu |

> ⚠️ Règle : Maximum 5 couleurs actives par écran

## 6. ICÔNES ET ILLUSTRATIONS

### Style recommandé :
- Icônes arrondies et amicales (style Phosphor Icons ou Heroicons)
- Illustrations vectorielles colorées avec motifs africains subtils
- Personnages représentant la diversité burkinabè
- Animaux locaux comme mascottes (lièvre, éléphant, etc.)

### Motifs africains :
- Patterns géométriques Bogolan en fond subtil
- Bordures inspirées du tissu Faso Dan Fani
- Formes organiques évoquant la savane

## 7. RÈGLES D'ACCESSIBILITÉ

1. **Contraste** : Ratio minimum 4.5:1 pour le texte
2. **Taille tactile** : Boutons minimum 44x44px
3. **Texte** : Taille minimum 14px, possibilité d'agrandir
4. **Couleurs** : Ne jamais utiliser la couleur seule pour transmettre l'info
5. **Audio** : Sous-titres pour toutes les vidéos
